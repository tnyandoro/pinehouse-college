# Pinehouse College website

Static website (no build step). Open `index.html` in a browser to preview.

- `index.html` holds all pages (Home, About, Academics, Admissions & Fees, Gallery, Contact).
- `images/` holds the logo and photos.
- Text marked with a yellow highlight and `[PLACEHOLDER]` is for you to edit.
- Replace the Facebook and Instagram URLs (search for `facebook.com/` and `instagram.com/`).

## Deploy with GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)`.
